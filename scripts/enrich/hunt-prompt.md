# Промпт охотничьего агента (шаблон для hunt-N.json)

Ты — охотник за интересными памятниками России. Прочитай файл
`C:\Users\J\source\memory\memorial-site\scripts\enrich\hunt-N.json` — там список регионов
(для каждого: сколько записей уже в каталоге и existingTitles — уже имеющиеся памятники).

Задача: для КАЖДОГО региона из файла найди 2–4 НОВЫХ интересных памятника/скульптуры,
которых нет в existingTitles. Приоритет: необычные (животные, еда, профессии, персонажи,
мини-скульптуры, народный юмор), малоизвестные исторические. НЕ бери: Лениных, стандартные
воинские мемориалы (кроме уникальных), бульварные клумбы-арт-объекты без истории.

ГДЕ ИСКАТЬ (важно!):
1. Местные туристические сайты и путеводители: запросы вида «что стоит посетить в N»,
   «что посмотреть в N необычное», «достопримечательности N скульптуры», «малая родина N
   памятник», региональные visit-порталы (visit...ru), «Большая страна», tur-ray, блоги
   краеведов. Там встречаются памятники, которых нет в Википедии — это самые ценные находки.
2. Русская Википедия (категории «Памятники N», статьи городов) — для проверки и деталей.
3. Новости региональных СМИ — для дат и историй открытия.

ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ к каждой находке:
1. ФОТО — свободная лицензия, только:
   - Wikimedia Commons (проверь страницу файла: описание/категория подтверждают памятник), URL:
     `https://commons.wikimedia.org/wiki/Special:FilePath/<ИМЯ_ФАЙЛА>?width=1600`
   - ИЛИ локальный файл ru.wikipedia (проверь лицензию на странице файла — только CC BY-SA / CC0 /
     public domain; НЕ бери «добросовестное использование»):
     `https://ru.wikipedia.org/wiki/Special:FilePath/<ИМЯ_ФАЙЛА>?width=1600`
   Памятник без свободного фото в зачёт НЕ идёт — пропусти и ищи другой.
2. КООРДИНАТЫ — именно памятника (не города): из статьи Википедии, карточки OSM
   (overpass/turism=artwork) или туристического сайта. Перепроверь второй строкой
   (Википедия + OSM идеально).
3. ИСТОРИЯ — fullHistory 2–4 абзаца УНИКАЛЬНОГО текста на русском: только проверяемые факты
   (автор, год, почему установлен, детали). НЕ выдумывай.
4. facts: 3–5 коротких фактов; factsSource { label, url } — лучший источник.

Формат записи:
{
  "title": "...", "city": "...", "region": "<как в файле задания>",
  "year": 1995 | null, "category": "Необычные|Исторические|Гастрономические|Архитектурные|Мини-скульптуры",
  "shortDescription": "≤200 символов", "fullHistory": "...",
  "facts": ["..."], "factsSource": { "label": "...", "url": "..." },
  "coordinates": { "lat": 0, "lng": 0 },
  "photos": [ { "url": "...", "source": "commons.wikimedia.org|ru.wikipedia.org", "sourceUrl": "страница файла" } ],
  "slugBase": "3-5 слов латиницей", "notes": "как проверял координаты/фото"
}

Результат запиши в `C:\Users\J\source\memory\memorial-site\scripts\enrich\out-hunt-N.json` — JSON-массив.
В финальном ответе: сколько нашёл по каждому региону, у скольких фото, какие источники помогли.
